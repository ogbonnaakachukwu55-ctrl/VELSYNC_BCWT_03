# Web3 Wallet Connector

A simple Web3 wallet connector built with HTML, CSS, JavaScript, and Ethers.js. It allows users to connect their MetaMask wallet to a webpage and view basic wallet information.

## Features

- Connect MetaMask wallet.
- Display connected wallet address.
- Display the connected blockchain network.
- Display wallet ETH balance.
- Disconnect wallet from the application interface.
- Detect account changes and update wallet information automatically.
- Detect network changes and reload the page.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Ethers.js v6
- MetaMask

## Live Demo

[Open Web3 Wallet Connector](https://ogbonnaakachukwu55-ctrl.github.io/VELSYNC_BCWT_03/)

## How to Run

1. Install the MetaMask browser extension.
2. Open the live demo using a browser with MetaMask enabled.
3. Click **Connect Wallet**.
4. Approve the connection request in MetaMask.
5. View your wallet address, network, and ETH balance.

You can also download or clone this repository and open `index.html` in your browser.
